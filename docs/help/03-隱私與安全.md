# 隱私與安全

## 別人看得到我的紀錄嗎？
看不到。每位使用者只能看到、編輯、刪除自己的紀錄。系統的每個查詢都限定目前登入的使用者，就算有人修改網址中的紀錄編號，也只會得到「找不到頁面」。

## 管理員看得到我的心情紀錄嗎？
管理頁面只顯示整體的使用統計數字（例如使用者人數、每天新增的紀錄數），不會顯示任何人的心情分數或備註內容。管理員看得到的是你主動送出的「問題回報」內容。

## 我的密碼安全嗎？
系統不會儲存你的密碼本身，只儲存經過雜湊（scrypt）處理後的值，即使資料庫外洩，也無法直接看出原本的密碼。建議不要使用和其他網站相同的密碼。

## 小幫手會把我的心情紀錄送出去嗎？
不會。小幫手的知識庫只有 MoodTrack 的說明文件，你的心情分數與備註不會被拿來回答問題。你在小幫手輸入的問題會被記錄，用來找出說明文件不足的地方。請不要在提問中輸入個人敏感資訊。

## 為什麼要登出？
登出會清除這個瀏覽器的登入狀態。在公用電腦或借用別人的手機時，用完請一定要登出。
